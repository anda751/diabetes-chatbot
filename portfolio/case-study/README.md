# Today Care case study

A buildless HTML/CSS/JavaScript presentation, following the Pawfect case-study structure: problem, workflows, engineering, screens, evidence, and next iteration.

Serve this directory with any static HTTP server. On Vercel, select no framework; the included configuration uses this directory as the output.

## Screenshots

Captured from local production builds using intercepted synthetic responses on 21 November 2026. No production API was contacted during capture. Fonts may load from the application's declared public font providers. All accounts, records, projects, and statistics are fixtures. The gallery is a presentation, not an authenticated public application demo.

Use the screen buttons, Left/Right/Home/End keys, and image enlargement. The native dialog supports Escape and keyboard focus. Reduced motion and no-JavaScript image links are supported.

## Evidence

8 regression checks and production builds passed. Read-only PostgreSQL connectivity with verified TLS passed. Android app and notification behavior were previously tested successfully, as confirmed by the project owner. This review did not repeat a device installation.
